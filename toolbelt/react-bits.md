# react-bits — animated components

**What:** A large library of animated, characterful React components and backgrounds (text effects, animated backgrounds, interactive bits) you can drop in. Copy-paste / CLI install, customizable.

**Use it when:** you want a distinctive animated accent on a React site — an eye-catching hero text effect, an animated background, a playful interactive element — without building it from scratch.

**Use sparingly:** these are *seasoning*, not the meal. One or two well-placed effects elevate; a page full of them looks busy and slow. Pick effects that serve the brief's tone (energetic vs calm) rather than "because it's cool."

**Install (per project):**
```bash
npx jsrepo add <component>   # per the react-bits docs / site
```
(Browse https://reactbits.dev to pick components, then install the ones you use.)

**Pairs with:** [shadcn/ui](shadcn.md) for structural UI, [GSAP](gsap.md)/[Lenis](lenis.md) for custom motion. Keep to the tone set in the intake `brief.md`; see [`../principles/motion.md`](../principles/motion.md).
