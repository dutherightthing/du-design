# transitions.dev — transition & motion inspiration

**What:** A reference library/showcase of page and element transitions (by Jakub Antalík). **Not a dependency** — a source of *ideas* and patterns for how things move between states/pages.

**Use it when:** you need inspiration or a vocabulary for transitions — how a page should enter/exit, how sections hand off, what a tasteful state change looks like. Browse it during intake (Phase 3 references) or when choosing a motion approach.

**How to use here:** treat it as a moodboard for motion. Pick a transition idea, then implement it with the right engine — [GSAP](gsap.md) for web, [HyperFrames](hyperframes.md) for video. Reference URL: https://transitions.dev

Related: the **motion-design** skill and [`../principles/motion.md`](../principles/motion.md) for the *why* behind a transition; [`../references/moodboards/`](../references/moodboards/) to save specific ones Jerry likes.
