# Universal principles

Applies to everything — websites, video, slides, graphics. If a medium-specific file conflicts, it wins; otherwise these hold.

## The big five

1. **One idea per unit.** One point per slide, one message per section, one focal point per frame. If a viewer has to work out where to look, you've already lost them.
2. **Say it once.** Don't state the same idea in the headline *and* the body *and* the icon *and* the caption. Redundancy reads as noise and padding, not emphasis. (See [`slides.md`](slides.md) for the deck-specific version — this is the #1 rule Jerry cares about.)
3. **Hierarchy is the whole job.** Every composition should have a clear 1st, 2nd, 3rd thing. Size, weight, color, and space create it. If everything is emphasized, nothing is.
4. **Space is not empty.** Negative space is an active tool — it creates focus, calm, and premium feel. Amateurs fill it; pros protect it.
5. **Restraint reads as quality.** One accent color, one or two typefaces, one motion idea. More options usually means less polish. When in doubt, remove.

## Contrast & focus
- Establish contrast on purpose: big vs small, bold vs light, color vs neutral, busy vs calm. Contrast *is* attention.
- Every screen/frame needs a single clear focal point. Squint at it — the thing that survives is your focal point. If nothing dominates, fix it.

## Color
- Pick a small palette: one dominant neutral, one accent, and a couple of supporting tones. See [`color.md`](color.md).
- Accent color earns attention *because* it's rare. Don't spend it everywhere.

## Type
- Two typefaces max (often one). A display/heading face and a workhorse body face. See [`typography.md`](typography.md).
- Set a type scale and stick to it; don't freestyle sizes.

## Alignment & grid
- Everything aligns to something. Use a grid; edges and baselines should line up. Misalignment is the most common "why does this look amateur" cause.

## Anti-slop checklist (reject these defaults)
- Centered hero + three feature cards + a gradient, with no reason.
- Every element the same size/weight (no hierarchy).
- Stock-y, generic imagery with no point of view.
- Rainbow of colors; five fonts; drop shadows on everything.
- Text that repeats the image, and an image that repeats the text.
- "Everything animates in" with no intent (see [`motion.md`](motion.md)).

## Process rules
- **Propose directions, don't guess one.** Always give Jerry options to react to.
- **Steal structure from what works.** If there's a reference, extract *why* it works (hierarchy, palette, spacing) before reproducing the look — use design-dna.
- **Cut, then cut again.** The first draft has too much. Removing is the highest-leverage edit.
