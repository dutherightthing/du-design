# References — taste inputs

Curated examples of "what good looks like," so the agent can ground directions in things Jerry actually likes rather than generic guesses. This grows as you collect.

## moodboards/
Things Jerry loves the look of — save a screenshot + a note on *why* (what specifically works: the palette? the type? the restraint? the motion?). During intake Phase 3, the agent can pull from here and run **design-dna** to extract tokens.

Suggested per-item format (`moodboards/<name>.md`):
```
# <name> — <url or source>
![screenshot](./<name>.png)
Why I like it: <the specific thing — palette / type / spacing / motion / mood>
Use for: <mediums or vibes this applies to>
```

## your-past-work/
Projects Jerry has shipped and liked, annotated with what worked. Over time this becomes the strongest signal of his taste — the agent studies it before proposing directions.

Keep it light: a screenshot/link + a sentence on why it was good is enough. Quality of notes matters more than volume.
